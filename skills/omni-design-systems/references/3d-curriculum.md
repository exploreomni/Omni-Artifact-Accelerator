# Spatial modeling practice

Eight focused modules extend the [existing S1–S12 curriculum](experience-curriculum.md); they are not eight new delivery gates. Use the relevant module for a demonstrated gap, or an original capstone for deliberate practice. Reading, installation and course completion do not prove expertise or retrain the model. Skill discovery, practiced judgment, reviewed artifacts and native qualification remain separate outcomes.

The [3D modeler](../../omni-3d-modeler/SKILL.md) owns geometry/fidelity; designers own task and composition; analysts own metric meaning; App engineering owns the viewer/runtime; motion owns choreography; QA reviews independent evidence. Work may stay with one agent where appropriate; these roles do not require a larger agent team.

## Modules

| Module / existing studios | Original practice | Critique and useful handoff |
| --- | --- | --- |
| M1 — Task and fidelity / S1–S3 | Given “inspect a field instrument,” decide what the user needs to see, which dimensions must be known and whether a diagram or spatial view helps. Choose a reasoned treatment; compare alternatives only when that resolves uncertainty. | Does spatial form add task value? Label illustrative versus source-constrained features and the unsupported claim the design avoids. |
| M2 — Object craft / S1, S3, S9 | Design an unbranded field terminal from original three-view sketches: body, hinge, screen and repeated keys. Resolve silhouette and named parts before seams or trim. | Inspect proportions, coherent relationships, readable detail and stable component identity. A manufacturer's resemblance or extra polygon count is not the criterion. |
| M3 — Procedural systems / S4, S10 | Describe a modular canopy or service-vehicle rack with original profiles, dimensions and bounded repetition. Change one parameter while preserving existing part IDs; predict counts and bounds before compilation. | Distinguish declarative design intent from actual supported operators. Reject an expansion that exceeds known limits; no scripts, copied node setups or unapproved libraries. |
| M4 — Materials and composition / S3, S4, S9 | Produce a material/lighting intent board for one object, with selected/unknown/restricted status treatments where data applies. Choose views that expose the decisive surfaces. | Does surface character clarify form without masking semantic color or exact values? Written intent does not establish actual lighting, contrast or visual polish. |
| M5 — Asset delivery / S9, S10 | Prepare a portable asset handoff with units, axes, rights, hierarchy, stable IDs, editable parameters and proposed output profile. Map it to an actual approved harness contract only when supplied. | Can another owner recover provenance and meaning? Unknown rights or support remain explicit. A format suffix, valid schema or successful export is not a safety or native-compatibility pass. |
| M6 — Inspection and tours / S7, S8, S11 | Design direct inspection or purposeful stops in a fictional public conservatory. Include return, interruption, explicit reset and a static/list route; a tour is optional when it adds no value. | Does each action reveal useful evidence? Check retained selection/camera and narrow/short-height priorities separately from actual motion comfort or runtime behavior. |
| M7 — Governed data mapping / S2, S4, S5, S10 | Map shelf bays or service-vehicle components to synthetic entity keys; choose a valid scoped comparison and handle null, absent and restricted results distinctly. | Independent expected values, grain and denominator come first. Geometry ID is not a row index, and decorative shape must not imply unsupported measurement. |
| M8 — Qualification and transfer / S11, S12 | Have a separate reviewer critique the current candidate, revise the consequential failure and retest the affected path. Apply the reasoning to an unrelated warehouse or vehicle brief without inheriting a prescribed layout. | Record source, computation, rendering, native and participant evidence separately. Intentional reuse is allowed; a changed skin or self-review does not establish transfer or independent qualification. |

Use original sketches, dimensional worksheets, neutral geometry briefs and material/view specifications when execution or rendering is unavailable. Generating arbitrary code is not a shortcut to completing a practice task. No Blender code/API, scripts, add-ons, copied/reconstructed node setups or implementation-derived algorithms may be used. Follow the shared [dependency policy](../../omni-artifact-accelerator/references/dependency-policy.md) before installation, import or execution.

## Structured judgment exercise

**Synthetic brief:** A maintenance planner needs to inspect a fictional field terminal, identify a selected assembly and compare service coverage. A body, hinge and screen are separate entities. Their illustrative envelope dimensions are 0.30 × 0.22 × 0.04 metres for the closed body; these are invented design constraints, not product measurements. The service sample contains body: 6 inspected of 8 eligible; hinge: 3 of 4; screen: inspected count unknown, 5 eligible. The sample is partial and does not describe a fleet.

Produce a compact practice record in existing design/QA evidence:

1. State the task and thesis, fidelity, design treatment and a simpler alternative if 3D would not earn its cost. Explain one tradeoff; no fixed composition or brand is supplied.
2. Describe original components, coordinate conventions, stable IDs, material intent and useful inspection views. State the unknown hinge articulation and detail rather than inventing engineering truth.
3. Map those three entities to the supplied sample, preserving the unknown numerator. Show valid per-entity values and state why the complete aggregate coverage cannot be calculated from this sample. Do not average percentages or call this fleet performance.
4. Specify selection → evidence → return, then a missing/late-result case and the applicable constrained layout. Include exact evidence outside the scene and a static alternative if motion is chosen.
5. Hand off a neutral brief. Serialize only to a supplied actual schema under the existing approval boundary; otherwise leave runtime artifacts ungenerated.
6. A separate reviewer derives numerical/dimensional expectations from this brief and critiques the chosen task path. Preserve the original candidate and consequential revision, naming the actual observation method and unrun lanes.

This exercise assesses reasoning, identity and meaningful handoff. It cannot certify fabrication accuracy, safe execution, native delivery or polished rendering. A second practice domain can use an original modular conservatory or maintenance vehicle with different task priorities; do not reuse the terminal composition by default. Do not require these specimens in every customer engagement.

## Optional linked study

These are selected historical access observations from **2026-10-23**, not live entitlement guarantees or mandatory prerequisites. Recheck only when current access affects the task. Do not play media, enroll, download assets or install tools by implication. “Training” here means original guidance, practice and critique, not fine-tuning or collecting course content into a corpus.

- [Blender 4.5 manual](https://docs.blender.org/manual/en/4.5/index.html): optional conceptual study of proportions, topology, hierarchy and material intent. Public/indexed documentation was accessible, with some direct pages returning access errors. Use no code, node setup, API or add-on from it; no Blender tool is required. Linked manual content and code have different rights; do not infer reuse from public access.
- [Introduction Hard Surface with Blender — Alfonso Alcaide](https://www.udemy.com/course/introduction-hard-surface-with-blender/): provider metadata listed it as free; useful conceptual topology and proportion topics. Enrollment and instructional quality were unobserved. Free-course certificates/Q&A/direct messaging were excluded by provider policy; tool-specific procedures/add-ons are outside this curriculum.
- [Making a Laptop — Abhijit Kapoor](https://www.udemy.com/course/making-a-laptop-blender-3d-modeling-level-2/): provider metadata listed a free introductory product course. Use conceptual part relationships only; no supplied assets, code or setup. Version/update and enrollment were unverified.
- [Advanced 3D Modeling and Architectural Design — Packt/Coursera](https://www.coursera.org/learn/packt-advanced-3d-modeling-and-architectural-design-0jdfm): relevant architecture syllabus, **not verified fully free**. The observed course FAQ required purchase or available aid beyond preview and offered no audit. No course or tool use is required for the original environment exercises.
- [MIT 6.837 lecture index](https://ocw.mit.edu/courses/6-837-computer-graphics-fall-2012/pages/lecture-notes/): optional conceptual coordinates/hierarchy study; the 2012 implementation environment is historical. Keep it as linked study, not copied implementation or commercial agent-corpus material; consult [current OCW terms](https://ocw.mit.edu/pages/privacy-and-terms-of-use/) for the actual intended use. This is a bounded reuse recommendation, not a legal determination.

Keep source/creator, checked date, observation limits and intended reuse in engagement research. Free reading is not redistribution permission. Create original specimens; do not bundle course transcripts, images, models or manufacturer assets. No full free production vehicle/building course or expert performance was established by this research.
