Inside the composition — choices, mechanics and tradeoffs

Two tasks, not two skinsThe dashboard establishes a fixed portfolio claim, reconciles contributions, then supplies monthly context. The App puts period and identity selection first. Both use the same 12 sales observations; neither fabricates a richer dataset.

Editorial emphasis + a comparison atlasOne large signed change creates hierarchy. A zero-centered contribution plot explains it. Repeated monthly panels share their scale, while direct labels make the exact evidence available without a legend hunt. Narrow layouts stack the evidence rather than shrink a desktop canvas.

Identity before choreographyThe comparison keeps Alder, Bay and Cedar in fixed row order. Open and filled endpoints distinguish periods. A 280ms ease-out movement changes only mark geometry; exact values commit immediately. Rapid changes retarget those same marks. Reduced motion or the checkbox produces the completed state immediately.

What the design does not proveThis original local specimen is not an import file or a verified native implementation. It has no query runtime, security boundary or customer acceptance. Contribution geometry and custom motion need separate capability qualification in a target. Static code checks are not rendered, keyboard-user or assistive-technology evidence.

Useful tradeoffsStable rows protect identity but do not expose changing rank as directly as a sorted view. A fixed zero-based scale supports magnitude comparison but compresses small changes. Exact endpoint labels and the table provide precision; the timeline restores evidence omitted by a two-period view.

Try a transfer, not a copyAsk what grain would be needed for a distribution, journey or retention view. Monthly sales do not supply those facts. Practice long labels and missing observations in a separate copy; the embedded fixture here remains unchanged. The original practice palette has no real brand affiliation.
