# SSRS migration specialist

Own SSRS source interpretation inside the existing
[accelerator engagement](../omni-artifact-accelerator/SKILL.md). Reuse the
[Report designer](../omni-report-designer/SKILL.md) and
[Report builder](../omni-report-builder/SKILL.md) for the target. Do not turn a
paginated report into an App or interactive dashboard without the user's choice.

Read the shared [RDL source contract](../omni-artifact-translator/references/rdl-report-source-contract.md)
for the working offline reader and [capture contract](../omni-artifact-translator/references/report-source-capture.md)
for immutable files, results and pure operation plans.

Preserve the exact RDL bytes and actual SSRS version, principal, item identity and
content path. Independently enumerate expected reports, datasets, parameters,
sections, repeated placements and dependencies. XML names and positional locators
are not catalog IDs. A parsed namespace is not full RDL schema validation or a
rendering pass; supplied metadata does not authenticate its source.

Keep query language/text and parameter bindings, default/null/blank/multiple-value
semantics, dataset/report/group filter stages, grouping/sorts, page breaks, headers,
footers, visibility, drill actions, resources and subreports. Preserve shared data
source/dataset references and every unresolved dependency. RDL expressions, custom
assemblies/code, stored procedures and connection strings are not safe to execute
merely because the definition is XML. No runtime loading, resource downloads or
credential extraction occurs during intake.

Interpret a deterministic structural subset; classify ambiguous calculations and
custom behavior for review rather than translating VB/SQL by guesswork. Reuse
existing qualified Omni semantics, with genuine model gaps routed through the
existing DMA handoff. This reader is not a DMA source producer or formula compiler.

For target artifact work, retain A–F gates, original decisions and independent
numerical expectations. The three E choices must preserve the same source scope
and fidelity requirements. Source export state does not choose the target cache,
refresh or distribution policy. No report, subscription or recipient send follows
automatically from capture permission.

SSRS REST planners emit fixed, unexecuted requests only. The current helper does
not log in, connect, decode binary reports or render exports. Qualify the actual
server/base path/version, read scope and side effects with the host before any
future execution; an evidence reference is not a grant. Missing native access
leaves a source-evidence and target-design handoff, never a fabricated deployment.
