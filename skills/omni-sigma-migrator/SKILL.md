# Omni Sigma Migrator

Own Sigma source expertise inside the [Artifact Accelerator](../omni-artifact-accelerator/SKILL.md).
Resume its existing engagement and source run. Direct invocation enters the same
workflow; do not start a second coordinator or replace independent QA.

Read the [connected workflow](../omni-artifact-accelerator/references/sigma-visual-run.md)
for executable tools and [evidence contract](../omni-artifact-translator/references/sigma-agent-bridge.md)
for accepted source shapes. Follow the shared
[dependency policy](../omni-artifact-accelerator/references/dependency-policy.md).
An installed runtime, hash, request or source connection is not dependency approval,
another person's access, target-write authority or migration acceptance.

## Qualify and capture the source

Recover the Sigma API region, organization, actual principal, workbook/page IDs,
selected tag/version/state and requested Omni destination. Use the local intake
helper to identify missing facts and generate bounded requests. Request credentials
through the host's secret channel, never chat, source JSON or a committed example.
After exact runtime review, use startup-selected check, inventory, snapshot and
capture operations. Discovery can precede workbook selection; workbook capture
does not require an unrelated data model. Preserve actual model dependencies when
present. Never select by title alone or reinterpret a workbook URL as verified ID.

Retain original definitions, page/element PNGs and result bytes separately. Optional
`includeContents=true` is **Beta**, current-workbook definition evidence; it is not
tagged visual evidence or a complete asset/security export. Official Sigma MCP
responses may supplement the bundle as already-transferred, pinned evidence.
Published, tagged, draft and saved-view states must not be silently merged.

Inventory every selected page, placement, visual and non-query object independently
of successful conversion. Preserve formulas, sort/null/grain semantics, formatting,
layout, control targets, drill/filter states, permissions/personas and unknown
facets. Keep actions, input-table/writeback, saved views, schedules and embeds as
explicit requirements with owners and cases. A screenshot cannot resolve them.
Use [behavior obligations](references/behavior-obligations.md) for source review.

## Coordinate architecture, design and delivery

Preserve A–F: verify access, analyze, build the traceable narrative, interview,
present exactly three equally scoped visual concepts and record the actual choice,
then resolve design and build. Capture can proceed before E; target artifact coding
and converter-package handoff cannot. At D retain audience, brand, quality ambition,
responsive contexts, visual treatments and the user's target cache/refresh policy.

Choose architecture explicitly. `reuse_existing` permits only verified existing
Omni bindings. `omni_semantic_reconstruction` preserves accepted warehouse relations
and excludes upstream dbt generation. `warehouse_first_refactor` requests separately
reviewed backend work through the existing
[DMA exchange](../omni-backend-handoff/references/cowork-contract.md).
Do not default to a route, infer a join, activate disabled AI conversion or flatten
unsupported calculations into plausible SQL.

Reuse SigmaMigrationAgent's reviewed converter package instead of reimplementing
its formulas, IDs or control mapping. Verify the entire package directory, original
source/target hashes and proposal binding. Preserve its interactive human terminal
review: never fabricate, pipe or replace that review with a chat selection or call
internal Session methods. If a trusted terminal handoff is unavailable, retain the
prepared work and exact next command; do not claim autonomous review completion.

The BI/App engineers prepare owned candidates through existing guarded adapters.
Named-draft changes, initial creation, App actions and publication retain their
separate capability/authority boundaries. No publisher is added by this skill.

## Return evidence, not a completion assertion

Return original IDs/files, independent inventory denominator, query/mapping
decisions, source state, capabilities, unresolved behaviors and candidate-bound
cases. Verify PNG/JSON/CSV bytes before use. Preserve exact numeric precision through
explicit normalization. Matching arbitrary rows establishes arithmetic agreement;
Sigma execution parity additionally needs bound source definition/state, effective
principal, complete population, freshness and corresponding target evidence.
Keep access, numeric, interaction, visual, accessibility and performance lanes
separate. Local fixture success is not live-tenant or business acceptance.
