# Behavior and acceptance handoff

The original selected inventory is the denominator. Preserve every included,
deferred, excluded, unavailable or unknown object with an explicit disposition.
Repeated report placements and source/provider identities remain distinct.

## Required review dimensions

- Analytical: provider grain, aggregation/projection, query/report/block filter
  order, merged dimensions, calculation context, sections/breaks/totals/ranks,
  source errors and complete provider populations.
- Interactive: prompt keys and use/display values, defaults/required/cascades,
  input controls and affected elements, reset, drill/navigation and conditional
  formatting. An input control definition is not proof of its effective state.
- Visual: default and narrow views, labels/legend/units, table totals, page
  breaks, print/export settings and accessibility.
- Operational: saved data versus executed refresh, source timestamps, partial
  refresh failures, selected target cache/expiry policy, scheduling/bursting and
  recipient/access requirements.
- Semantic/security: Universe version, join/context/derived-table dependencies,
  row/column/object policy, permitted and denied personas. Admin access is not
  the intended user's effective access.
- Crystal: engine-specific sections, suppression, subreports, running totals,
  group/page boundaries and printer/export obligations, separately from WebI.

For each obligation record source object/locator, consumer, original evidence,
target route/binding, owner, expected behavior, result/state evidence, disposition,
review reference and outstanding gap. Owners remain unassigned when not known.

## Numerical evidence

Use the supplied raw export, an explicit parser profile and exact capture binding.
Keep raw and formatted values separate, preserve null/error distinctions, decimal
precision and row identity. Record report/provider/element, principal, locale,
timezone, prompt/filter/input-control state, refresh status and completeness.
Do not reconcile only a top-N subset or infer all-provider success from one export.

Normalization proves deterministic interpretation, not source authenticity.
Numeric QA must recheck capture/result/source/candidate pins and observed-state
continuity. Missing/changed context, incomplete providers, source error values,
unqualified parser/profile or unsupported report-engine binding is inconclusive.
An equal hand-authored CSV cannot clear these gaps.

Keep numerical, interaction, visual, accessibility, performance, effective access,
publication and business acceptance separate. Any unobserved lane remains
unobserved in the return to DMA and in the customer handoff.

## Qualification milestones

Local source checks establish only the implemented input/profile behavior.
Connected metadata needs a trusted host and exact server qualification. Query,
refresh, native render/export, lifecycle cleanup, complete Universe extraction
and Crystal fidelity each need their own supported profile and evidence.
No live tenant is assumed. A delivery without that evidence states the remaining
qualification explicitly and retains its obligations; it does not remove them.
