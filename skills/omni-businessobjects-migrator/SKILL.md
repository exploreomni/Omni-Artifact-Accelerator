# BusinessObjects migration specialist

Work inside the existing [accelerator engagement](../omni-artifact-accelerator/SKILL.md).
Own source interpretation and coverage; reuse the product owner, data analyst,
BI engineer, designers, security review and independent QA. A source product name
does not select the Omni target or authorize execution.

Read [source competencies](references/source-competencies.md) to qualify the
server/report-engine profile, [assignments](references/subagent-assignments.md)
for bounded collaboration, and [behavior handoff](references/behavior-handoff.md)
before declaring coverage. The [source contract](../omni-artifact-translator/references/businessobjects-source-contract.md)
and [run guide](../omni-artifact-accelerator/references/businessobjects-visual-run.md)
describe implemented interfaces and limits.

## Discovery before translation

Record the actual package revision, original request, HTTPS source identity,
BI version/service pack/patch, principal, document ID/CUID, report engine,
report/provider/element IDs, Universe types, selected scope and evidence references.
Inventory folders/documents, repeat placements, hidden content, dependent reports,
schedules, exports and recipient requirements without silently fetching them.
Use an independently supplied expected inventory; a parsed export cannot prove
that it includes every source object or that the intended user has access.

WebI, UNV, UNX, classic Crystal and Crystal Enterprise are distinct profiles.
Version-qualified reading does not imply tenant qualification. Unknown versions,
missing fields, unsupported definitions and denied/private scope remain explicit.
Do not decode or execute opaque WID, UNV, UNX, RPT, BIAR or LCMBIAR files, follow
URLs in exports, or treat a rendered XML export as a report definition.

## Preserve behavior and partner with DMA

Retain original formulas, query/report filter stages, provider grain and refresh
status, merged dimensions, calculation contexts, prompt key/use/display values,
input controls, sections, breaks, totals, conditional formatting and navigation.
Source errors remain errors, never zero. Translation is an evidence projection,
not a universal formula compiler or a security-policy migration engine.

Reuse reviewed Omni bindings first. Classify each unresolved calculation as
existing binding, semantic reconstruction, warehouse work, presentation logic or
manual review. Send grain, join/context, Universe, derived-table and access gaps
through [DMA cowork](../omni-backend-handoff/references/cowork-contract.md), with
original evidence, selected route, affected consumers and independent expectations.
No BusinessObjects-specific DMA producer or SDK is supplied. Source labels and
local hashes do not authenticate authority or establish complete Universe security.

## Keep A–F intact

For a new engagement: A verifies data and the actual user's access; B qualifies
providers, queries and independent results; C creates a traceable narrative.
At D capture fidelity/redesign, dashboard/App/both, audience, ambition, brand,
devices, exports/print, navigation, optional spatial/3D visuals and the target
[cache/refresh policy](../omni-product-owner/references/data-refresh-policy.md).
Source refresh schedules never choose target caching defaults.
At E present exactly three concrete viable concepts at the accepted quality bar
and retain the actual user selection before detailed design and F coding.
Reuse valid prior decisions for an existing engagement, not generic source defaults.

Treat operation permissions separately from these design decisions. Metadata
GETs can cause source work; inspect query parameters and output format. Local
MCP tools cannot enable connected capture. The qualified capture service receives
authority from an external host callback, not an agent-writable file.
No source save, refresh, rendering, scheduling, cleanup, SDK loading or target
write is implied by an import or by a request to migrate.

Deliver independent numerical, visual, interaction, accessibility, performance,
effective-access and business-acceptance status. Keep unsupported Crystal,
Universe and operational requirements visible rather than labelling them migrated.
