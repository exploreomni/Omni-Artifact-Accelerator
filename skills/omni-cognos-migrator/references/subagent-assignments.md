# Scoped responsibility profiles

Use the existing orchestrator and task-routing contract. These are responsibilities,
not a requirement to spawn four agents. Delegate only independent bounded work;
include the original request, source pins, selected scope, stage, outputs, acceptance
criteria and unresolved dependencies in every packet.

| Profile | Existing roles and responsibility | Handoff |
|---|---|---|
| Source and inventory | Cognos specialist with artifact translator: retain original report XML, independent expected occurrences and source identity; classify unsupported evidence. | Query/layout/control/dependency inventory, exact locators, gaps; no candidate code or source execution. |
| Analytical semantics | Data analyst with BI engineer/backend handoff: inspect original calculations, filter stages, aggregate/total rules, prompts and model/security dependencies. | Reuse candidates, metric/population expectations and scoped DMA requests; unknown formulas remain review work. |
| Product and experience | Product owner, storyteller, branding and permitted App/dashboard designer: preserve audience, fidelity, narrative, visual ambition, navigation, exports and print obligations. | Three viable concepts and the selected detailed design at E; source names do not choose the target surface. |
| Independent acceptance | QA analyst using originals and independent expectations: assess candidate numerical, interaction, visual, access, accessibility and performance evidence. | Findings, adaptations and unobserved lanes; static source inspection cannot certify runtime or effective access. |

The lead consolidates the result. Keep schema reconstruction and customer-specific
assumptions out of the reusable skill. Design/coding, dependency approval and
publication remain governed by their existing gates.
