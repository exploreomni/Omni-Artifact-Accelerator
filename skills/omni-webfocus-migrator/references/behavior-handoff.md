# WebFOCUS behavior and handoff

Use the shared [migration ledger](../../omni-qa-analyst/references/migration-behavior.md)
and [migration lifecycle](../../omni-backend-handoff/references/migration-lifecycle.md).
The source specialist contributes evidence to these records; it cannot certify its
own build or create a separate acceptance system.

| Obligation | Preserve | Evidence gap response |
| --- | --- | --- |
| Identity | Version, principal, repository/application paths, native IDs, original hashes, definitions versus placements | Retain missing/denied/opaque items; no title-only joins |
| Data semantics | DEFINE/COMPUTE stages, detail/summary grain, BY/ACROSS, totals, nulls, formats, joins and intermediate datasets | Send precise source-located backend requirements; never drop unsupported clauses |
| Visuals | Buckets, series, axes, labels, conditional styles and ordered overrides | Propose supported mapping/adaptation; preserve opaque scripts |
| Composition | Pages, sections, containers, repeated content, navigation and responsive intent | Keep complete selected denominator independently of chart extraction |
| Controls | Prompts, required/default/multiselect/cascade behavior, affected/unaffected content and reset | Require exact inspected target bindings or reviewed adaptation |
| Actions | Drill, Auto Linking, hierarchy navigation, parameters, return state and custom code | Capture actual persona-specific behavior; do not execute source actions to discover it |
| Results | State, principal, population, preview limit stage, raw rows, totals, watermark and completeness | Unknowns keep comparison inconclusive despite equal numbers |
| Freshness | Sampling, pagination, source cache and actual target App policy | Ask target-policy question at D; no inferred bypass, timer or expiry |
| Operations | ReportCaster/bursting/export consumers, libraries, permissions and owners | Explicit pending operational work; no implied retirement or replacement |

Retain original result bytes and explicit types/currency/date rules. An independent
report export is not evidence of a page placement's applied parameters. A screenshot
is visual evidence for one state; it is not a query, access or completeness oracle.
Capture missing runtime behavior as required cases rather than inventing defaults.

Use the existing reuse_existing, omni_semantic_reconstruction or
warehouse_first_refactor route. For DMA exchanges, retain source_platform webfocus,
frontend IDs, original source pins and independent expected cases in a bounded,
dependency-complete slice. Do not pass an unsupported raw export as a DMA contract.
The bridge recognizes only qualified producer revisions; separate producer closure
pins cannot be substituted merely because one parser file is identical.

A–F applies to all new engagements. Data and narrative precede product discovery;
exactly three concrete visual options and actual selection precede code. Preserve
quality ambition and the selected surface; a paginated report, portal or offline
document may require a different disposition from an interactive dashboard. Carry
brand/website, advanced visual choices and refresh policy through design and QA.

Target engineers reuse current verified Omni bindings or resolve backend gaps first.
Keep dashboard and App candidates and receipts distinct. Source changes, changed
state, new backend candidates and target edits reopen affected evidence. Native
writes, publication, source retirement and schedule changes retain separate grants.
Return unresolved obligations and actual review status. Local tests, source capture,
native readback, rendered quality, effective access and business acceptance remain
separate lanes; no live WebFOCUS pilot has been established by package fixtures.
